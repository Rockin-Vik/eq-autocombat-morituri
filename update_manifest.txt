note=- **Melee no longer stays off on the next mob after an enraged one dies.** The "has become ENRAGED" line only carries a name, so MoriAC marked every mob with that name on your extended target as enraged. A mob usually dies while enraged, and then no "is no longer enraged" line comes, so the other "a gnoll"s stayed marked. MoriAC kept auto-attack off on the next one for up to 3 minutes. Mobs enrage at low HP, so now only the lowest-HP mob with that name is marked. To skip enrage handling altogether, untick **Stop Attacking While The Target Is Enraged** in Setup -> Settings. (The Alerts plugin only plays the sound; it never stops your attack.)
