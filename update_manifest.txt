note=## 2026-11-23
note=
note=- **Melee no longer creeps up on a mob one step at a time.** When the game said "Your target is too far away", MoriAC only moved 8 units closer and then forgot about it, so the approach to the next mob stopped short again. The result was step, swing, "too far away", step... This hit big mobs most, because their approach distance comes from the size the game reports for them. Now the first "too far away" moves you straight to just inside your **Melee distance**, and MoriAC keeps that shorter reach for that mob (for 10 minutes), so it doesn't stop short again. If the game still says too far, it moves 4 units closer each time.
note=
note=- **New `/ac why`: see why the puller skips a mob.** Target the mob and type `/ac why`. MoriAC runs the same search the puller runs, with your current radius, height, level and pull-list settings, and prints what it decided about that mob. For example: past the search radius, past the max height difference, outside the level range, not on the pull list, marked unreachable, no nav path to it, or a nav path that is too winding. It also says which mob the search would pick instead. It doesn't change anything. Use it when Hunt, Camp or Lure walks past a mob you expected it to fight.
note=
note=- **Puller (Hunt) walks to mobs again instead of standing still.** Since the "closest to walk to" change (2026-10-31), each search checked the nav path length of at most 15 mobs. That limit was meant to stop the search once it had a good pick, but it also stopped a search that had found nothing yet. Where the nearest 15 mobs all had long, winding routes (more than 2.5 times the straight-line distance, common in dungeons and on hills), the search gave up and Hunt waited, even with a mob further out that had a clean path. Walking up close to a mob made it the first one checked, so it got picked. Now the 15-mob limit only applies once a mob has been picked. This applies to Camp and Lure pulls too.
note=
note=- **Melee no longer stays off on the next mob after an enraged one dies.** The "has become ENRAGED" line only carries a name, so MoriAC marked every mob with that name on your extended target as enraged. A mob usually dies while enraged, and then no "is no longer enraged" line comes, so the other "a gnoll"s stayed marked. MoriAC kept auto-attack off on the next one for up to 3 minutes. Mobs enrage at low HP, so now only the lowest-HP mob with that name is marked. To skip enrage handling altogether, untick **Stop Attacking While The Target Is Enraged** in Setup -> Settings. (The Alerts plugin only plays the sound; it never stops your attack.)
