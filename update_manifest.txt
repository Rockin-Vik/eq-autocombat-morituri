note=## 2026-11-25 (4)
note=
note=- **Boxnet is safer by default.** Peers can no longer make your boxes run plain slash commands unless you turn "also run slash commands" on. Even then, code-loading, chat, petition and logout commands (`/lua`, `/mac`, `/say`, `/tell`, `/ooc`, `/1`, `/quit` and similar) are always refused, also when wrapped in `/nomodkey`, `/squelch`, `/noparse`, `/timed N` or `/docommand`. Nested `/ac net` and `/multiline` are refused. Only the transport's sender name is trusted.
note=- **Spell memorising can no longer hang MoriAC.** Waiting for the casting window now gives up after 15 seconds.
note=- **Player chat can no longer trigger cast lockouts.** The "not ready", "insufficient mana" and "can't cast while" events now match only EQ's own system messages.
note=- **Saves are crash-safe.** Loadouts and the DPS, map, inventory and chat-trace files are written to a temp file and renamed into place, keeping a `.bak`. Loadouts load from `.tmp`/`.bak` if the main file is missing.
note=- **A UI error no longer freezes the game.** Page draws in the main and mini windows are guarded; an error shows in the window and is logged once.
note=- **Plugin fixes.** Enabling an enabled plugin does nothing; reloading calls the old instance's cleanup first. The Plugins/Update pages no longer start the plugin manager while drawing.
note=- **Death clears pending memorise, bard song and downtime steps.**
note=- **Alerts:** pattern edits apply when you leave the field; patterns that match every line (`#*#`, `#1#`, `*`) are rejected or skipped.
note=- **Updater downloads files from the exact commit in the manifest.**
note=- **Performance:** combat tick every 0.2 s measured from tick start; reposition after "too far" runs in the combat tick; fewer XTarget and spawn lookups; spell mana/duration cached; AA/ability rows rebuilt every 15 s instead of 1 s; AA ID scan spread over ticks; cheaper sorts on the Plugins page and HUD effects.
note=

note=- **Settings files get the server name on servers where `EverQuest.ServerName` is empty (Perky Crew).** They used to be saved as `moriac_loadout__<char>.lua`; now they're `moriac_loadout_Perky_Crew_<char>.lua`. Your existing settings are copied over the first time (never on Morituri). Servers where `ServerName` works keep their file names.

note=
note=- **`/lua run mac` no longer freezes the game.** The short-name launcher started MoriAC with `dofile`, which MacroQuest's Lua cannot pause through, so MoriAC never gave a frame back to the game. It now loads MoriAC as a normal Lua call. `/lua run moriac` was not affected.

Camping to another server now reloads that server's settings, even with the same character name.
